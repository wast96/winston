# Project-specific noise for check_numbers.py (pass with --noise).
# One regex per line, NO trailing comments (load_extra_noise keeps the whole
# line as the pattern). These are numerals that are names or idiom in
# 《千里江山图》, NOT quantities — stripping them keeps the number check readable.
#
# 牌九 = pai gow, the domino gambling game (九 is part of the name)
牌九
# 四散 = "scatter in all directions" (四 is idiom, not a count)
四散
# Personal names containing 千 (qian = 1000): the Chen brothers.
陈千元
陈千里
# 十足 = "fully / utterly" (intensifier, not the count 10)
十足
# 百货公司/百货 = department store ("hundred goods", not the count 100)
百货
# 四合 = (dusk) "closing in on all sides" (四 is idiom, not a count)
四合
# 颠三倒四 = "topsy-turvy / incoherent" (idiom, 三/四 not counts)
颠三倒四
# 百叶窗 / 百叶 = louvered shutter ("hundred leaves", not the count 100)
百叶
# 四下 = "on all sides / all around" (四 is idiom, not a count)
四下
# 第二天 = "the next day / the following day" (二 is an idiomatic ordinal, not a count)
第二天
# 年三十 = New Year's Eve (name of the last day of the lunar year, not the count 30)
年三十
# 四川 = Sichuan (place name in 北四川路 North Sichuan Road; 四 is not a count)
四川
# 二(?=岁): the built-in "十多" rule strips 十多 out of 二十多岁 ("twenty-odd years old")
# and orphans a stray 二; this drops that artifact while a real 两岁 still counts.
二(?=岁)
# 吴四宝 = Wu Sibao, a personal name (四 is part of the name, not a count)
吴四宝
# 三成坊 = Sancheng Fang, a lane/place name (三 is part of it, not a count)
三成坊

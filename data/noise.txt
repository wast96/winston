# Project noise file for check_numbers.py — pass with --noise data/noise.txt
#
# One regex per line. '#' comment lines only — NO trailing comments; the
# loader keeps the whole non-# line as the pattern.
#
# RULES (each learned on a real book):
#   1. ORDERING IS LOAD-BEARING. Longest literal first. A rule that is the
#      prefix of a longer form eats the front of it and orphans the tail:
#      a prisoner ID 五一三 must appear BEFORE a 五一 (May Day) rule, or 五一
#      strips the prefix and a phantom 三 is reported dropped.
#   2. Prefer a lookbehind over a broad strip. Built-in numeral-initial rules
#      are auto-guarded now, but a rule you write that can match the TAIL of
#      a larger number still needs (?<![零一二两兩三四五六七八九十百千万萬億]).
#   3. This file runs BEFORE the built-in list, so an entry here can protect
#      one of your numbers from a greedy built-in (strip 两三百 whole before
#      the generic 两三 fires and orphans the 百).
#   4. Noise only ever removes SOURCE numerals, so it can never mask a drop.
#      If a flag is a REAL quantity, fix the English to carry the value.
#      Never noise a real number.
#   5. Every entry gets a comment line above it: what the idiom/name means,
#      and what phrase the English uses instead. An uncommented entry cannot
#      be audited and will eventually be deleted by someone it burns.
#
# WHAT BELONGS HERE (accumulate as the check flags them):
#   - personal names containing numerals      (陈千里, 吴四宝, 小五子)
#   - place names                             (九龙, 四川, 八仙桥, 百老汇)
#   - four-character idioms not in the built-ins
#   - lexical-numeral compounds               (百货, 三轮车, 零钱, 五金)
#   - decade/era labels                       (二十年代, 十八世纪)
#   - weekday indices                         (星期[一二三四五六], 礼拜[一二三四五六])
#   - the source's own note markers, if any   (\[\d+\])
#
# Example entries (delete these; they are here to show the format):
# the Nine Dragons of Kowloon — rendered "Kowloon"
# 九龍
# weekdays carry no quantity — rendered "Monday" etc.
# 星期[一二三四五六]

王八

# 两 following 百/千/万 is the tael measure word (银两/白银X两), not the count
# 2 — the source writes "三百两银子" (300 taels), whose cn_to_int otherwise
# reads as 302 because 两 is also the digit 2. Strip only that trailing 两;
# 两位/两杯/两条(count 2) has no numerical prefix and stays. The rule is
# a lookbehind so the built-in _guard is not needed.
(?<=[百千万萬])两
# --- B03 (ch03 丹凤公主 / ch04 大金鹏王) ---
# 五十两一锭 (fifty taels the ingot): the tael 两 sits between 五十 and 一(锭),
# and cn_to_int reads the whole run 五十两一 as 51. Strip 两一 (tael marker +
# the bare measure-一 of 一锭) when it sits between 十 and 锭, leaving 五十锭 =
# 50. MUST precede the (?<=十)两 rule below, or that rule strips the 两 first
# and 五十一锭 still reads 51. Rendered "gold ingots of fifty taels each" (ch03).
(?<=十)两一(?=锭)
# 两 as the tael measure word after 十 (五十两 = 50 taels; 一百多两 handled by
# the 多 rule below). Parallel to the 百/千/万 rule above: without it 五十两
# parses as 52 (十→50, then 两→digit 2). The count "two" (两位/两条/两腿) never
# follows 十, so this is safe. Rendered "fifty taels" etc. (ch03, the golden
# ingots the Princess sends to pay for Huo Xiu's smashed hut).
(?<=十)两
# 两 as the tael measure word after 多 (一百多两 = "a hundred-odd taels"): the
# 多 breaks the numeral run, so the trailing 两 would otherwise orphan a stray
# 2. Rendered "a hundred taels and more" (ch03). The count "two" never follows
# 多, so this is safe.
(?<=多)两
# 丑八怪 = "ugly freak/hag" (lit. "ugly eight-monster"); the 八 is idiom, not a
# count. Rendered "frightful hag" / "a hag" (ch03).
丑八怪
# 五色缤纷 / 五彩衣 = "a riot of colour" / "motley robe"; the 五 ("five colours")
# is the colour idiom, not a count. Parallel to the B02 五彩缤纷 rule. Rendered
# "flowers of every colour" / "motley colours" (ch03). Longest-first: the 缤纷
# forms first, then the bare colour prefixes.
五色缤纷
五色
五彩

# "four directions" idiom, not a count. Rendered "flashed with authority"
# (ch04, the traitor Ping Duhe's triangular eyes).
四射

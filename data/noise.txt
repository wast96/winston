# Project-specific noise regexes for check_numbers.py (B01+).
# Each line is a regex stripped from the SOURCE before numerals are counted.
# Add an entry ONLY for a numeral that is not a real quantity (a name/address
# with digits, a decade label, a set phrase), with a note on why.

# decade labels: "70年代" = the 1970s, not the quantity 70
\d+年代
# street address on Route Lafayette: 四一三○八号 is a house number, not counts
四一三[○〇]八
# 三天两头 = "every other day" (idiom), not the counts 3/2
三天两头
# 一清早 = "first thing in the morning", the 一 is not a count
一清早
# 第二天/第二日 = "the next day" (idiom); the 2 is not a count. (第二次 "the
# second time" and 第三天 "the third day" ARE counts and are left in.)
第二[天日]
# weekday names: 星期六 = Saturday, etc.; the digit names the day, not a count
星期[一二三四五六日天]
# idiomatic intensifiers, not quantities:
五彩
万种
十二分
# 百合 = "lily" (recurring simile 百合初放 "a lily just opening"); the 百 is not 100
百合
# 百乐门 = the Paramount (proper noun, dance hall); the 百 is not 100
百乐门
# 十字架 = "cross" (the shape); the 十 is not the count 10
十字架
# 四围 = "all around"; the 四 is not a count
四围
# 两个字 = "the two characters" of a Chinese word (meta-linguistic); not a count
两个字
# 梅百器 = Mario Paci (proper name, the conductor); the 百 is not 100
梅百器
# 零星/零落/零乱 = "scattered / dwindled / disordered"; the 零 is not the quantity 0
零[星落乱]
# 四川 = Sichuan (place name, as in 北四川路 North Sichuan Road); the 四 is not 4
四川
# 四为 = a digitization slip for 因为 ("because") in ch14; the 四 is not the count 4
四为
# 两样 = "no different" (set phrase 没有两样); the 两 is not the count 2
两样
# 十足 = "to the full / completely" (idiom 十足发挥); the 十 is not the count 10
十足
# 光芒万丈 = "blazing with radiance" (idiom, of Mei Yingzi as the sun); 万丈 is not a count
光芒万丈
# 丈 is a Chinese unit of length (~3.3 m); a numeral + 丈 is rendered to feet in English
# (一丈 -> "ten feet", 二丈 -> "twenty feet"), so the numeral is unit-converted and cannot
# survive source-to-target as-is. Strips the numeral before 丈 (not 丈夫 "husband").
[一二三四五六七八九十两]丈
# 四十二四十三 = an unpunctuated speed range "42-43" (the needle "始终在四十二四十三上");
# the numeral parser miscomputes it as a single 83. The real values 42/43 are rendered
# ("forty-two, forty-three"); the whole-hour "一点钟" (per hour) is stripped by 点钟 above.
四十二四十三
# 一时 handled by the built-in measure list; 万分 already built in.
# --- B04 (ch18-ch21) additions ---
# 二房东 = "sublandlady / second landlord" (set term for a sublessor); 二 is not a count
二房[东東]
# 飘零 = "to drift / fall (of leaves)"; the 零 is not the quantity 0
[飘飄]零
# 二○号 = ward No. 20 at Renji Hospital, written 二 + circle-zero (U+25CB/U+3007); the
# parser cannot join the circle to 二, so it orphans a bare 二 read as 2 (the real
# value 20 is rendered "ward number twenty"). Strips the ward token whole.
二[○〇]号
# 四更 = the fourth night-watch (~1-3 a.m.), a time-of-night term rendered "the small
# hours"; the 四 is not a count. (更 as watch: 一更..五更.)
[一二三四五]更
# 六角 = "hexagonal / six-cornered" (crystal shape in the ch21 vision); 六 is not a count
六角
# 大千世界 = "the vast universe" (Buddhist 三千大千世界); the 千 is not the quantity 1000
大千世界
# --- B05 (ch22-ch25) additions ---
# 两手 = "both hands", 两膝 = "both knees" (body-part idiom); the 两 is not the count 2
两[手膝]
# 连三接四 = "one after another" (idiom, of the tension coming in a rush); 三/四 not counts
连三接四
# 零碎 = "odd / sundry (tasks)"; the 零 is not the quantity 0 (cf. 零星/零落/零乱 above)
零碎
